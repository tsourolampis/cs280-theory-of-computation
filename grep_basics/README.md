# ΗΥ-280 — Εργαστήριο `grep` πάνω σε `customers.csv`

Στόχος είναι η εξοικείωση σας με το εργαλείο `grep`. Κάθε βασικό `grep -E` μοτίβο περιγράφει μια **κανονική γλώσσα**: τα strings που ταιριάζουν στο pattern. Η μηχανή matching ελέγχει αν μια γραμμή περιέχει τέτοιο pattern. Οι άγκυρες `^`/`$` και τα κόμματα βοηθούν να περιγράψουμε πιο ακριβώς τι ζητάμε. Οι shell pipelines (`tail`, `grep -v`, `grep -c`, `grep -o`) συνθέτουν περισσότερες επεξεργασίες και **δεν είναι όλα απλώς ένα DFA**. Χρησιμοποιούμε ένα απλό CSV χωρίς quoted commas, escaped quotes ή ενσωματωμένες αλλαγές γραμμής. Για γενικό CSV χρειάζεται CSV parser.

## 1. Τα αρχεία

Το εργαστήριο αποτελείται από:

- `customers.csv`: το dataset που θα αναζητούμε.
- `grep_demo.sh`: το έτοιμο Bash script που εκτελεί **19** παραδείγματα και εκτυπώνει τις αντίστοιχες εντολές.
- `README.md`: αυτός ο οδηγός, με εξηγήσεις και αναμενόμενα αποτελέσματα.

Η σειρά των **οκτώ στηλών** είναι σημαντική:

| # | Πεδίο | Τι σημαίνει |
|---:|---|---|
| 1 | `id` | Αναγνωριστικό πελάτη |
| 2 | `name` | Όνομα |
| 3 | `email` | Διεύθυνση email |
| 4 | `phone` | Τηλέφωνο |
| 5 | `postal` | Ταχυδρομικός κώδικας |
| 6 | `country` | Κωδικός χώρας |
| 7 | `amount` | Ποσό |
| 8 | `status` | Κατάσταση πληρωμής |

## 2. Πώς το τρέχω στο Terminal

Αποθήκευσε τα `customers.csv`, `grep_demo.sh` και `README.md` **στον ίδιο φάκελο**. Άνοιξε το Terminal στον φάκελο, για παράδειγμα:

```bash
cd ~/Downloads
ls -l customers.csv grep_demo.sh README.md
bash grep_demo.sh
```

Το script δείχνει κάθε εντολή με αρίθμηση `[01]`–`[19]` και αμέσως μετά τις γραμμές που επιστρέφει. Δεν απαιτεί εγκατάσταση επιπλέον εργαλείων.

**Για μεμονωμένη δοκιμή**, πληκτρολόγησε/επικόλλησε όποια εντολή από την ενότητα 4 θέλεις. Π.χ.:

```bash
grep -E '^([^,]*,){5}GR,' customers.csv
```

**Σημείωση:** τα μονά εισαγωγικά `'...'` διατηρούν τους χαρακτήρες της regex χωρίς να τους ερμηνεύσει το shell. Αν μεταβάλεις το CSV, οι αναμενόμενες έξοδοι θα αλλάξουν.

## 3. Μικρό λεξικό regular expressions

| Σύνταξη | Σημασία |
|---|---|
| `^` | Αρχή γραμμής (εκτός από όταν είναι στην αρχή κλάσης `[^...]`). |
| `$` | Τέλος γραμμής. |
| `.` | Ένας οποιοσδήποτε χαρακτήρας. |
| `\.` | Η κυριολεκτική τελεία. |
| `[0-9]` | Ένα ψηφίο. |
| `[A-Za-z]` | Ένα αγγλικό γράμμα. |
| `[^,]` | Ένας χαρακτήρας που **δεν** είναι κόμμα. |
| `*` | Μηδέν ή περισσότερες επαναλήψεις του προηγούμενου στοιχείου. |
| `+` | Μία ή περισσότερες επαναλήψεις. |
| `?` | Μηδέν ή μία επανάληψη (προαιρετικό). |
| `{5}` | Ακριβώς πέντε επαναλήψεις. |
| `{2,}` | Τουλάχιστον δύο επαναλήψεις. |
| `(...)` | Ομαδοποίηση. |
| `A\|B` | Εναλλακτική **μέσα σε regex**: A ή B. |
| `\+` | Το κυριολεκτικό σύμβολο `+`. |

Στο `grep -E` (Extended Regular Expressions / **ERE**), οι `()`, `{}`, `+`, `?` και ο τελεστής επιλογής `|` χρησιμοποιούνται απευθείας ως μεταχαρακτήρες. Επίσης, το `grep` εκτυπώνει **ολόκληρη τη γραμμή** που περιέχει ένα match, εκτός εάν χρησιμοποιούμε `-o` ή `-c`.

**Η πιο σημαντική τεχνική για CSV:**

```text
^([^,]*,){5}GR,
│└──┬───┘└┬┘└┬┘
│   │     │  └── το 6ο πεδίο είναι ακριβώς GR
│   │     └───── επανάλαβε 5 φορές
│   └─────────── ένα πεδίο (χαρακτήρες εκτός κόμματος + κόμμα)
└─────────────── αρχή γραμμής
```

Τα πέντε πεδία που προσπερνάμε είναι **`id, name, email, phone, postal`**. Δεν αναζητούμε μια τυχαία εμφάνιση του `GR`, αλλά τον κωδικό χώρας στη **σωστή στήλη**.

### 02. Πελάτες από Ελλάδα: το `country` είναι το 6ο πεδίο

**Εντολή:**

```bash
grep -E '^([^,]*,){5}GR,' customers.csv
```

**Αναμενόμενη έξοδος:**

```text
101,Maria,maria@acme.gr,+30 6912345678,71201,GR,1250.50,PAID
103,Eleni,eleni@@bad.gr,2810-555000,71305,GR,410.00,PAID
105,Nikos,nikos@foo.gr,+30 6987654321,71A02,GR,72.00,DUE
```

**Ανάλυση, από αριστερά προς τα δεξιά:**

- **`^`** — Αρχή γραμμής. Ξεκινάμε μετρώντας πεδία από το `id`.
- **`[^,]`** — Οποιοσδήποτε χαρακτήρας **εκτός κόμματος**. Τα `[]` είναι κλάση χαρακτήρων και το αρχικό `^` **μέσα** στην κλάση σημαίνει άρνηση.
- **`[^,]*`** — Μηδέν ή περισσότεροι χαρακτήρες που δεν είναι κόμμα· δηλαδή το περιεχόμενο ενός πεδίου.
- **`[^,]*,`** — Ένα ολόκληρο πεδίο **μαζί με το κόμμα που ακολουθεί**.
- **`([^,]*,)`** — Ομαδοποίηση ενός τέτοιου πεδίου για να επαναληφθεί ολόκληρο.
- **`{5}`** — Ακριβώς **πέντε επαναλήψεις**: `id, name, email, phone, postal,`.
- **`GR`** — Οι ακριβείς χαρακτήρες `G` και `R`, αμέσως μετά τα πέντε πρώτα πεδία.
- **Τελικό `,`** — Βεβαιώνει ότι το έκτο πεδίο είναι **ακριβώς** `GR` και δεν αρχίζει απλώς με `GR`.

**Τι μαθαίνουμε:** Ουσιαστικά: **από την αρχή**, παράλειψε πέντε πεδία, έλεγξε ότι το έκτο είναι `GR`. Παράδειγμα: `101,Maria,maria@acme.gr,+30 6912345678,71201,` + `GR,` + `1250.50,PAID`. Το `GR` μέσα σε άλλο πεδίο **δεν αρκεί**.

**Προσοχή:** Το μοτίβο αγκυρώνεται ως προς τη χώρα, αλλά όχι στην αρχή της γραμμής· προϋποθέτει τη συγκεκριμένη σειρά πεδίων στο απλό CSV.

4:103,Eleni,eleni@@bad.gr,2810-555000,71305,GR,410.00,PAID

### 09. Emails με μια απλή εύλογη μορφή

**Εντολή:**

```bash
grep -E ',[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,},' customers.csv
```

**Αναμενόμενη έξοδος:**

```text
101,Maria,maria@acme.gr,+30 6912345678,71201,GR,1250.50,PAID
102,John,john@example.com,617-555-0199,02115,US,89.10,DUE
104,Alice,alice@lab.edu,212-555-0104,10027-1234,US,999.99,HOLD
105,Nikos,nikos@foo.gr,+30 6987654321,71A02,GR,72.00,DUE
```

**Ανάλυση, από αριστερά προς τα δεξιά:**

- **Αρχικό `,`** — Ξεκινά ένα CSV πεδίο.
- **`[A-Za-z0-9._%+-]`** — Επιτρεπόμενοι χαρακτήρες στο μέρος **πριν από** το `@`: γράμματα, αριθμοί και `._%+-` (η παύλα στο τέλος της κλάσης είναι κυριολεκτική).
- **`+` μετά την κλάση** — Απαιτεί **τουλάχιστον έναν** χαρακτήρα από αυτή την κλάση.
- **`@`** — Ακριβώς ένας χαρακτήρας `@` στην επιλεγμένη θέση.
- **`[A-Za-z0-9.-]+`** — Τουλάχιστον ένας χαρακτήρας στο τμήμα domain.
- **`\.`** — **Κυριολεκτική τελεία**, π.χ. πριν από `com`. Αν γράφαμε σκέτο `.`, στην regex θα σήμαινε «οποιοσδήποτε χαρακτήρας».
- **`[A-Za-z]{2,}`** — Τουλάχιστον δύο αγγλικά γράμματα στο τελευταίο μέρος, π.χ. `gr`, `com`, `edu`.
- **Τελικό `,`** — Το email πρέπει να τελειώνει πριν από το επόμενο CSV πεδίο.

**Τι μαθαίνουμε:** Οι Maria, John, Alice, Nikos ταιριάζουν· το `eleni@@bad.gr` δεν ταιριάζει. Πρόκειται για **heuristic** και όχι πλήρη έλεγχο εγκυρότητας email.

**Προσοχή:** Το μοτίβο απαιτεί ένα πεδίο (ανάμεσα σε κόμματα) με ακριβώς ένα `@`, γιατί καμία κλάση δεν επιτρέπει `@` ή κόμμα· γι' αυτό απορρίπτεται το `eleni@@bad.gr`. Δεν είναι όμως πλήρης έλεγχος: δεν είναι δεμένο με την τρίτη στήλη, δέχεται και domain όπως `a@..gr` ή `a@-x.gr`, και δεν ελέγχει DNS ή RFC.

### 10. Βρες εγγραφές χωρίς εύλογη μορφή στο πεδίο `email`

**Εντολή:**

```bash
tail -n +2 customers.csv | grep -Ev '^([^,]*,){2}[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,},'
```

**Αναμενόμενη έξοδος:**

```text
103,Eleni,eleni@@bad.gr,2810-555000,71305,GR,410.00,PAID
```

**Ανάλυση, από αριστερά προς τα δεξιά:**

- **`tail -n +2`** — Αφαίρεσε την επικεφαλίδα από το input.
- **`|` εκτός εισαγωγικών** — Το **pipe του shell** στέλνει τις γραμμές της πρώτης εντολής στη δεύτερη· δεν είναι εδώ regex alternation.
- **`-v`** — **Αντιστροφή**: εκτύπωσε τις γραμμές που **δεν** ταιριάζουν στην regex.
- **`^([^,]*,){2}`** — Παράλειψε τα **δύο πρώτα πεδία** `id,name,`, ώστε ο έλεγχος να αρχίζει ακριβώς στο τρίτο (`email`).
- **`[A-Za-z0-9._%+-]+`** — Μη κενό local part.
- **`@`** — Διαχωριστικό local part / domain.
- **`[A-Za-z0-9.-]+\.[A-Za-z]{2,}`** — Domain, κυριολεκτική τελεία και suffix τουλάχιστον δύο γραμμάτων.
- **Τελικό `,`** — Τέλος του πεδίου email.

**Τι μαθαίνουμε:** Επειδή ο `grep` έχει `-v`, η έξοδος περιλαμβάνει **μόνο την Eleni**. Είναι ένα εύχρηστο μοτίβο για να εντοπίζουμε υποψήφια σφάλματα δεδομένων.

### 11. Ελληνικού τύπου κινητά με προαιρετικό `+30`

**Εντολή:**

```bash
grep -E ',(\+30[ -]?)?69[0-9]{8},' customers.csv
```

**Αναμενόμενη έξοδος:**

```text
101,Maria,maria@acme.gr,+30 6912345678,71201,GR,1250.50,PAID
105,Nikos,nikos@foo.gr,+30 6987654321,71A02,GR,72.00,DUE
```

**Ανάλυση, από αριστερά προς τα δεξιά:**

- **Αρχικό `,`** — Ξεκίνημα πεδίου τηλεφώνου.
- **`\+`** — Κυριολεκτικό σύμβολο **συν**. Χρειάζεται escape επειδή το σκέτο `+` είναι ποσοδείκτης.
- **`30`** — Ο κωδικός χώρας.
- **`[ -]`** — Ένας χαρακτήρας: **κενό ή παύλα**.
- **`[ -]?`** — Προαιρετικό κενό/παύλα μετά το `+30`.
- **`(\+30[ -]?)?`** — Ολόκληρη η ομάδα `+30` και το πιθανό διαχωριστικό είναι προαιρετική.
- **`69`** — Το τηλέφωνο αρχίζει με `69`.
- **`[0-9]{8}`** — Ακολουθούν ακριβώς οκτώ ψηφία, άρα συνολικά δέκα για το κινητό.
- **Τελικό `,`** — Το πεδίο τηλεφώνου τελειώνει εδώ.

**Τι μαθαίνουμε:** Αναγνωρίζει τα δύο κινητά της Maria και του Nikos. Π.χ. `6912345678`, `+30 6912345678` και `+30-6912345678` περνούν τη συντακτική δοκιμή.

### 12. Ελληνικές εγγραφές με **μη** πενταψήφιο postal

**Εντολή:**

```bash
tail -n +2 customers.csv | grep -E '^([^,]*,){5}GR,' | grep -Ev '^([^,]*,){4}[0-9]{5},GR,'
```

**Αναμενόμενη έξοδος:**

```text
105,Nikos,nikos@foo.gr,+30 6987654321,71A02,GR,72.00,DUE
```

**Ανάλυση, από αριστερά προς τα δεξιά:**

- **`tail -n +2`** — Παράλειψε το header.
- **Πρώτο `grep -E`** — Επέλεξε όλες τις ελληνικές εγγραφές: `^([^,]*,){5}GR,`.
- **`|`** — Πέρασε μόνο τις ήδη επιλεγμένες ελληνικές γραμμές στον επόμενο έλεγχο.
- **Δεύτερο `grep -Ev`** — **Απόρριψε** όσες έχουν σωστό πενταψήφιο postal: `^([^,]*,){4}[0-9]{5},GR,`.
- **`-v`** — Κράτησε το **συμπλήρωμα** των σωστών postal μέσα στις ελληνικές εγγραφές.

**Τι μαθαίνουμε:** Έτσι εμφανίζεται μόνο ο Nikos με `71A02`. Σημαντικό: **δύο φίλτρα** υλοποιούν τη λογική `country = GR` **ΚΑΙ** `postal δεν έχει 5 ψηφία`.

### 13. Εντόπισε domain `example.com` με πραγματική τελεία

**Εντολή:**

```bash
grep -E ',[^,]+@example\.com,' customers.csv
```

**Αναμενόμενη έξοδος:**

```text
102,John,john@example.com,617-555-0199,02115,US,89.10,DUE
```

**Ανάλυση, από αριστερά προς τα δεξιά:**

- **Αρχικό `,`** — Ξεκίνημα comma-delimited πεδίου.
- **`[^,]+`** — Τουλάχιστον ένας χαρακτήρας που δεν είναι κόμμα.
- **`@example`** — Το ακριβές κείμενο `@example`.
- **`\.`** — Κυριολεκτική τελεία `.`· χωρίς escape, το `.` θα ταίριαζε και σε `exampleXcom`.
- **`com,`** — Το ακριβές `com` και τέλος πεδίου.

**Τι μαθαίνουμε:** Επιστρέφει τον John. Είναι παράδειγμα της διάκρισης ανάμεσα στο **regex wildcard** `.` και στον **κυριολεκτικό χαρακτήρα** `\.`.

### 14. Αναζήτηση του ονόματος Maria χωρίς διάκριση πεζών/κεφαλαίων

**Εντολή:**

```bash
grep -iE '^([0-9]+,)maria,' customers.csv
```

**Αναμενόμενη έξοδος:**

```text
101,Maria,maria@acme.gr,+30 6912345678,71201,GR,1250.50,PAID
```

**Ανάλυση, από αριστερά προς τα δεξιά:**

- **`-i`** — **Ignore case**: `maria` ταιριάζει και με `Maria`.
- **`^`** — Αρχή γραμμής.
- **`[0-9]+`** — Ένα ή περισσότερα ψηφία για το `id`.
- **`([0-9]+,)`** — Ολόκληρο το πρώτο πεδίο `id,`.
- **`maria,`** — Το δεύτερο πεδίο πρέπει να είναι ακριβώς Maria, αγνοώντας την πεζοκεφαλαιοποίηση.

**Τι μαθαίνουμε:** Ο στόχος εδώ είναι **το πεδίο name**, όχι τυχαία εμφάνιση της ακολουθίας χαρακτήρων `maria` στο email.

### 15. Εξαγωγή μόνο της τρίτης στήλης (emails)

**Εντολή:**

```bash
tail -n +2 customers.csv | grep -oE '^[^,]*,[^,]*,[^,]*' | grep -oE '[^,]+$'
```

**Αναμενόμενη έξοδος:**

```text
maria@acme.gr
john@example.com
eleni@@bad.gr
alice@lab.edu
nikos@foo.gr
```

**Ανάλυση, από αριστερά προς τα δεξιά:**

- **`tail -n +2`** — Παράλειψε header.
- **Πρώτο `-o`** — **Only matching**: αντί για ολόκληρη γραμμή, τύπωσε μόνο το τμήμα που ταιριάζει.
- **Πρώτο `^`** — Ξεκίνα από την αρχή κάθε CSV εγγραφής.
- **Πρώτο `[^,]*,[^,]*,[^,]*`** — Πιάσε το `id,name,email` μέχρι το τέλος του τρίτου πεδίου, χωρίς το επόμενο κόμμα.
- **Δεύτερο `grep -oE`** — Πάρε από το ενδιάμεσο αποτέλεσμα μόνο το κομμάτι μετά το τελευταίο κόμμα.
- **Δεύτερο `[^,]+$`** — Μία ή περισσότερες μη-κόμμα θέσεις **μέχρι το τέλος** του ενδιάμεσου κειμένου.

**Τι μαθαίνουμε:** Το πρώτο `grep` εξάγει π.χ. `101,Maria,maria@acme.gr`, το δεύτερο κρατά το `maria@acme.gr`. Η Eleni **εμφανίζεται** παρότι έχει malformed email: κάνουμε extraction, όχι validation.

**Προσοχή:** Η διαδικασία βασίζεται σε απλό CSV **χωρίς quoted commas**. Για πραγματικό CSV με εισαγωγικά χρησιμοποιούμε CSV parser.

### 16. Μέτρησε γραμμές με status `PAID`

**Εντολή:**

```bash
grep -cE ',PAID$' customers.csv
```

**Αναμενόμενη έξοδος:**

```text
2
```

**Ανάλυση, από αριστερά προς τα δεξιά:**

- **`-c`** — **Count**: τύπωσε το **πλήθος των γραμμών** που ταιριάζουν, όχι το περιεχόμενό τους.
- **`,PAID$`** — Comma, `PAID`, τέλος γραμμής: ακριβώς το status `PAID`.

**Τι μαθαίνουμε:** Το αποτέλεσμα είναι `2`, επειδή Maria και Eleni έχουν status `PAID`. Το `grep -c` **δεν μετρά συνολικά matches** όταν υπάρχουν πολλά ανά γραμμή.

### 17. Μέτρησε πόσοι πελάτες έχουν χώρα `GR`

**Εντολή:**

```bash
grep -cE '^([^,]*,){5}GR,' customers.csv
```

**Αναμενόμενη έξοδος:**

```text
3
```

**Ανάλυση, από αριστερά προς τα δεξιά:**

- **`-c`** — Εκτύπωσε μόνο το πλήθος γραμμών που ταιριάζουν.
- **`^([^,]*,){5}`** — Προσπέρασε τα πέντε πρώτα CSV πεδία.
- **`GR,`** — Το έκτο πεδίο πρέπει να είναι ακριβώς `GR`.

**Τι μαθαίνουμε:** Το αποτέλεσμα είναι `3`: Maria, Eleni, Nikos.

### 18. Εκτύπωσε αριθμούς γραμμών για εγγραφές US

**Εντολή:**

```bash
grep -nE '^([^,]*,){5}US,' customers.csv
```

**Αναμενόμενη έξοδος:**

```text
3:102,John,john@example.com,617-555-0199,02115,US,89.10,DUE
5:104,Alice,alice@lab.edu,212-555-0104,10027-1234,US,999.99,HOLD
```

**Ανάλυση, από αριστερά προς τα δεξιά:**

- **`-n`** — Πρόσθεσε τον αριθμό **φυσικής γραμμής** του αρχείου, με το header να μετρά ως γραμμή 1.
- **`^([^,]*,){5}`** — Προσπέρασε τα πέντε πρώτα πεδία.
- **`US,`** — Ακριβώς `US` στη στήλη country.

**Τι μαθαίνουμε:** Οι εγγραφές του John και της Alice βρίσκονται αντίστοιχα στις γραμμές **3** και **5**, όχι στις γραμμές 2 και 4 (που θα είχαν αν δεν μετρούσαμε το header).

### 19. Έλεγξε για κενά πεδία

**Εντολή:**

```bash
tail -n +2 customers.csv | grep -nE ',,|^,|,$' || echo '(no matches)'
```

**Αναμενόμενη έξοδος:**

```text
(no matches)
```

**Ανάλυση, από αριστερά προς τα δεξιά:**

- **`tail -n +2`** — Παράλειψε το header.
- **`-n`** — Εμφάνισε αριθμό γραμμής **του input του grep** (εδώ μετά το tail), αν βρεθεί λάθος.
- **`|` μέσα στο regex** — Εναλλακτική ανάμεσα σε τρία μοτίβα.
- **`,,`** — Δύο συνεχόμενα κόμματα: **κενό εσωτερικό** πεδίο.
- **`^,`** — Κόμμα στην αρχή: **κενό πρώτο** πεδίο.
- **`,$`** — Κόμμα στο τέλος: **κενό τελευταίο** πεδίο.
- **`|| echo ...`** — Λογικός τελεστής του **shell**: αν ο `grep` δεν βρει τίποτα (exit status 1), τύπωσε `(no matches)`. Διαφορετικό από το regex `|`.

**Τι μαθαίνουμε:** Με το παρόν dataset **δεν υπάρχουν κενά πεδία**. Επομένως βλέπουμε `(no matches)`. Παρ’ όλα αυτά υπάρχουν *άλλου τύπου* σφάλματα, όπως `eleni@@bad.gr` και `71A02`.
